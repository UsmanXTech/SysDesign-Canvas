# Component artwork

The architecture canvas uses transparent SVG artwork so icons remain crisp at every zoom level.

- Generic infrastructure concepts are original project illustrations.
- Redis uses the Redis brand mark from [Simple Icons](https://github.com/simple-icons/simple-icons), sourced from `icons/redis.svg`.
- Simple Icons is distributed under CC0, but brand names and logos remain subject to their owners' trademark and brand-use rules. See the [Simple Icons disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).

All SVG files have transparent backgrounds and can be rasterized to PNG for downstream exports when needed.
